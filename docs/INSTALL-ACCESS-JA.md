# インストール後のログインとパスワード

[English](INSTALL-ACCESS-EN.md) | [한국어](INSTALL-ACCESS-KO.md) | [日本語](INSTALL-ACCESS-JA.md)

## アカウントの動作

- bootstrapとFloop3のインストーラーは`root`パスワードを作成・変更しません。既存のroot認証情報をそのまま使います。
- LuCIは専用のFloop3パスワードではなくLinuxの`root`アカウントを使います。端末の設定でSSHパスワード認証が許可されている場合も同じrootパスワードです。
- Language and Styleで`en`、`ko`、`ja`を選ぶと表示言語だけが変わります。アカウントや認証情報は作成されません。
- rootパスワードが未設定なら、管理画面をネットワークに公開する前に設定してください。SoftBank純正ファームウェアのアカウント状態は別途確認してください。インストーラーは状態を推測・上書きしません。

## 推奨設定

1. 初回は信頼できる有線LANまたはプライベートWi-FiからのみLuCIを開きます。
2. 長く固有のrootパスワードを設定します。他の機器、Wi-Fi、メールと使い回さず、ソースツリー・ログ・インストール報告に記録しないでください。16文字以上のパスフレーズを推奨します。
3. 対応している場合は **System → Administration → Router Password** から変更するか、認証済みSSH/UARTのrootシェルで`passwd`を実行します。
4. SSHパスワード認証が不要なら公開鍵認証を使い、端末のポリシーに従ってパスワード認証を無効にします。
5. TCP/8080を公衆WANへ直接公開しないでください。bootstrapは`http://<LAN-IP>:8080/`でLuCIを提供し、ファイアウォールではLANブリッジからの入力だけを許可します。このHTTP通信は暗号化されないため、同一ネットワークの第三者に認証情報やセッションを見られる可能性があります。信頼できるネットワークだけで利用し、リモート管理にはVPNまたは別途検証済みのHTTPS終端を使用してください。

## インストール確認

- 既存のrootパスワードでログインできることを確認します。インストーラーは認証情報を表示・初期化しません。
- Language and StyleにEnglish、한국어、日本語が表示されることを確認します。
- LuCI標準画面とFloop3専用メニューの両方が翻訳されていることを確認します。カタログは別々です。
- ブラウザーの既存セッションからログアウトし、再ログインして言語と認証を確認します。
