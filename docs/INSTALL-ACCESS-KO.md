# 설치 후 로그인 및 비밀번호 원칙

## 계정 동작

- bootstrap과 Floop3 설치기는 `root` 비밀번호를 생성·변경하지 않습니다. 기존 장치의 root 자격 증명은 그대로 유지됩니다.
- LuCI 로그인은 별도 Floop3 비밀번호가 아니라 Linux `root` 계정을 사용합니다. SSH 비밀번호 인증도 장치 설정이 허용하면 같은 root 비밀번호를 사용합니다.
- Language and Style에서 `en`, `ko`, `ja`를 선택하는 것은 화면 언어만 바꾸며 계정이나 인증 정보를 만들지 않습니다.
- 신규 OpenWrt 설치처럼 root 비밀번호가 비어 있다면 네트워크에서 관리 UI를 사용하기 전에 root 비밀번호를 설정하십시오. SoftBank 순정 장치는 기존 계정 상태를 별도로 확인해야 하며, 설치기가 이를 추정하거나 덮어쓰지 않습니다.

## 권장 설정

1. LuCI를 신뢰하는 유선 LAN 또는 개인 Wi-Fi에서만 처음 엽니다.
2. 길고 고유한 비밀번호를 root에 설정합니다. 다른 장치, Wi-Fi, 이메일과 재사용하지 말고 소스 트리·로그·설치 보고서에 기록하지 않습니다. 긴 문장형 암호(예: 16자 이상)를 권장합니다.
3. 장치에서 제공한다면 LuCI의 **System → Administration → Router Password**에서 변경하거나, 인증된 SSH/UART root 셸에서 `passwd`를 실행합니다.
4. SSH 비밀번호 로그인이 필요하지 않다면 SSH 공개키 인증을 사용하고 비밀번호 로그인은 장치 정책에 맞춰 끕니다.
5. TCP/8080을 공인 WAN에서 직접 열지 않습니다. 현재 bootstrap은 LuCI를 `http://<LAN-IP>:8080/`로 제공하고 LAN bridge 입력만 방화벽에서 허용합니다. 이 HTTP 경로는 TLS로 암호화되지 않아 같은 네트워크의 공격자가 로그인 정보나 세션을 관찰할 수 있습니다. 신뢰하지 않는 네트워크에서는 접속하지 말고, 원격 관리는 VPN 또는 별도로 검증된 HTTPS 종단을 거치십시오.

## 설치 확인

- root 계정에 기존 비밀번호가 유지되는지 확인합니다. 설치기는 인증 정보를 출력하거나 초기화하지 않습니다.
- Language and Style에서 English, 한국어, 日本語가 보이는지 확인합니다.
- 각 언어에서 LuCI 기본 화면과 Floop3 전용 메뉴가 함께 번역되는지 확인합니다. 기본 UI 카탈로그와 Floop3 자체 카탈로그는 별도 파일입니다.
- 변경 후 브라우저의 기존 세션을 로그아웃하고 새로 로그인해 언어·인증 동작을 확인합니다.
