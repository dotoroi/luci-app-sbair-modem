# 物理SIM・APN・LTE/5Gバンドの設定

このガイドは、互換性のあるFloop3リリースを導入したSoftBank Air 6のメーカー版ファームウェアを対象とします。LuCIから操作でき、SSHコマンドやCodexは不要です。メニュー名はファームウェア、翻訳、リリースにより多少異なる場合があります。

## 1. 物理SIMへ切り替える

1. SIMカードのサイズを機器の説明書で確認します。不明な場合はカードを切ったりアダプターを無理に使ったりしないでください。ルーターの電源を切ってカードを挿入し、再び電源を入れます。
2. LuCIの **モバイルネットワーク → SIM/eSIM** を開きます。
3. **現在のSIM / SIM Mapping** でカード種類と状態を確認します。SIMトレイを使う場合は **物理SIM（通常SIM）** に切り替えます。切替中はモデムの電波が一時停止し、AT応答が約30～60秒止まることがあります。完了するまで別のモデム操作を開始しないでください。
4. 通常SIMと表示され、状態が `READY` であることを確認します。PIN/PUKを求められた場合、推測で何度も入力せず、カード事業者の案内を確認してください。
5. 他社SIMで `SIM lock` と表示された場合、契約上利用できることを確認してください。解除が必要な場合だけFloop3の案内に従います。SIM切替とは別の操作で、電波の再初期化中に接続が途切れます。

## 2. 通信事業者のAPNを適用する

SIMを認識した後、SIM/eSIMページの **通信設定 → APN** を開きます。Floop3はICCIDごとにAPNを保存するため、SIMごとに設定が保持されます。

1. **SIMからAPNを読み込む** を押します。事業者SIMから得た候補を入力欄に入れるだけで、保存・適用はしません。
2. APN、認証方式、ユーザー名、パスワードを、契約プランに対応する事業者の案内と照合します。候補が得られない、または誤っている場合は事業者指定値を入力します。APNは事業者・プラン・SIMにより異なるため、共通値を仮定しないでください。
3. 事業者が不要としている場合はユーザー名・パスワードを空欄、認証を `なし` にします。事業者指定がある場合だけPAP/CHAPと認証情報を設定します。
4. **保存して適用** を選びます。他のSIM用プロファイルを先に用意する場合は **保存のみ** を選び、現在の回線には適用しません。
5. 現在のWAN APNと `Applied` 状態を確認します。`Not applied` または通信できない場合は、網登録状態、APN/認証、プランのデータ利用可否を別々に確認します。SIMからAPN候補を取得できてもインターネット接続の成功を意味しません。

IMSは事業者がIMSサービスに必要としている場合だけ有効にします。データAPNとは別の設定で、SMS配信を保証するものではありません。APNの認証情報を共有しないでください。

## 3. LTE/5Gバンドを選び網登録を確認する

1. LuCIの **モバイルネットワーク → 電波/バンド** を開きます。
2. 表示される一覧を区別します。
   - **対応バンド**：モデムが報告する能力
   - **有効バンド**：モデムで現在許可されている一覧
   - **接続中のバンド**：現在の基地局で実際に利用しているバンド
3. その地域・プランで事業者が使うバンドを選びます。確かな情報がなければ、対応バンドをすべて有効にしておくのが安全です。LTEをすべて解除しないでください。5G NSAはNR接続の前にLTEアンカーを必要とします。
4. **適用** を押し、確認画面のLTE/NR変更内容を確認します。電波が一時的に切れる場合があります。セルラーWANが落ちてもLuCIを操作できるよう、ルーター管理用Wi-Fi/LANに接続したままにしてください。
5. Floop3は網登録を待ちます。時間内に登録できなければ、以前のバンド設定に戻して結果を表示します。画面を閉じず、ジョブの状態を確認します。
6. 完了後、登録事業者、登録状態、接続方式、接続中バンド、WAN状態を確認します。LTEのみ表示され5Gが空の場合、NSA構成でNRがまだ追加されていない可能性があります。対応一覧にあるだけでは、地域の電波・事業者の許可・網登録を保証しません。

保存したバンド選択は起動時にFloop3が再適用できます。モデムの有効マスク自体は再起動でメーカー既定値に戻ることがあるため、再起動後に実際の接続バンドと登録を確認してください。

## 4. 接続失敗を順番に切り分ける

| 画面の状態 | 確認項目 |
|---|---|
| SIMなし/読取不可 | カードの向き・装着・規格、物理SIMマッピング、SIMロック/PIN |
| SIM `READY`、網未登録 | エリア、バンド制限、プラン/ローミング許可、ロック状態 |
| 網登録済み、WAN/APN未適用 | 現在のICCIDのAPN、認証、適用状態 |
| APN適用済み、インターネット不可 | データ利用権限・容量制限、事業者のIP方式指定、WAN状態 |
| バンド変更後に未登録 | 自動復元の結果を確認。組み合わせを連続変更せず対応バンド全体へ戻す |

まずFloop3画面で失敗段階と復元結果を確認してください。推測したATコマンド、モデム初期化、連続再起動は行わないでください。識別情報表示を有効にした場合、ICCID/EID/電話番号を公開しないでください。
