# Floop3 調査記録と作業案内

このフォルダーには、Floop3 に関する過去の記録をまとめています。言語パックの引き継ぎ資料、確認された RPC・転送エラーと修正記録、インストーラーのレビュー、改行コードの再発防止策、RPC の静的確認、削除記録が含まれます。

## 対象範囲と注意事項

- 各資料は異なる日付に行った個別の確認を記録したものです。記載されたすべての状態が現在も続いていることを示すものではありません。
- 公開にあたり、LAN アドレスと機器内バックアップのパスを一般化しました。パスワード、SSH 秘密鍵、モデム識別情報、キャリブレーションデータ、ファームウェアのパーティションダンプは含まれていません。
- 機器の動作に関する記録は過去の調査証拠であり、インストール手順書ではありません。機器を変更する前に、最新のプロジェクト資料を確認し、復旧手段を確保してください。
- 保存された報告書の本文は韓国語です。この README の概要は英語・日本語・韓国語から選択できます。
