# 일반 SIM, APN, LTE/5G 밴드 설정

이 안내는 호환되는 Floop3 릴리스가 설치된 SoftBank Air 6 제조사 펌웨어를 대상으로 합니다. LuCI에서 진행할 수 있어 SSH 명령이나 Codex가 필요하지 않습니다. 메뉴 이름은 펌웨어·번역·릴리스에 따라 조금 다를 수 있습니다.

## 1. 물리 SIM으로 전환

1. SIM 트레이에 맞는 카드 규격을 장치 설명서에서 확인합니다. 크기를 모르면 자르거나 어댑터를 억지로 끼우지 않습니다. 전원을 끄고 카드를 장착한 뒤 다시 켭니다.
2. LuCI의 **모바일 회선 → SIM/eSIM** 페이지를 엽니다.
3. **현재 SIM / SIM Mapping**에서 카드 종류와 SIM 상태를 확인합니다. 실제 SIM 트레이를 쓸 때는 **물리 SIM(일반 SIM)** 으로 전환합니다. 전환 중에는 모뎀 전파가 잠시 꺼지고 AT 응답이 약 30–60초 멈출 수 있습니다. 완료될 때까지 다른 모뎀 조작이나 새 전환을 시작하지 않습니다.
4. 상태가 일반 SIM이고 SIM 상태가 `READY`인지 확인합니다. `PIN`/`PUK` 요청이면 임의 입력을 반복하지 말고 카드 통신사 안내를 확인합니다.
5. 다른 통신사 SIM에서 `SIM lock`이 표시되면 통신사와 계약 조건상 사용 권한이 있는지 확인합니다. 잠금 해제가 필요한 경우에만 Floop3의 안내를 읽고 진행합니다. 잠금 해제는 SIM 전환과 별개이며, 전파 재초기화 중 연결이 끊길 수 있습니다.

## 2. 통신사 APN 적용

SIM/eSIM 페이지의 **통신 설정 → APN**에서 현재 카드가 인식된 뒤 설정합니다. Floop3는 ICCID별로 설정을 저장하므로 SIM을 바꾸면 그 카드에 저장한 프로필을 선택합니다.

1. **SIM에서 APN 읽기**를 눌러 통신사 SIM이 제공하는 APN 제안을 불러옵니다. 이 동작은 입력란만 채우며 저장이나 적용은 하지 않습니다.
2. 제안된 APN, 인증 방식, 사용자명/암호가 해당 요금제에 맞는지 통신사 안내와 대조합니다. 자동 제안이 없거나 틀리면 통신사에서 받은 값을 입력합니다. APN 값은 사업자·요금제·SIM 종류에 따라 다르므로 임의의 공통값을 쓰지 않습니다.
3. 보통 사용자명/암호와 인증이 필요 없으면 비워 두고 인증 방식은 `없음`으로 둡니다. 통신사가 제공한 경우에만 PAP/CHAP과 계정 정보를 설정합니다.
4. **저장 및 적용**을 누릅니다. 다른 SIM에 쓸 프로필을 미리 입력할 때는 **저장만**을 눌러 현재 회선에 즉시 적용하지 않습니다.
5. 페이지에서 현재 WAN APN과 `Applied` 상태를 확인합니다. `Not applied`이거나 데이터가 안 되면 회선 등록 상태, APN, 인증, 요금제의 데이터 사용 가능 여부를 각각 확인합니다. SIM에서 받은 APN 제안만으로 인터넷 연결 성공을 판정하지 않습니다.

IMS 옵션은 음성/SMS IMS 서비스에 필요한 경우에만 통신사 안내에 따라 켭니다. 이는 일반 데이터 APN과 별도이며, SMS 전달 성공을 보장하지 않습니다. APN 자격 증명을 다른 사람과 공유하지 않습니다.

## 3. LTE/5G 밴드 선택 및 등록 확인

1. LuCI의 **모바일 회선 → 신호/밴드** 페이지를 엽니다.
2. 화면의 표시를 구분합니다.
   - **지원 밴드**: 모뎀이 보고한 기능 목록
   - **사용 설정 밴드**: 모뎀의 현재 허용 목록
   - **연결 중인 밴드**: 현재 기지국에서 실제 사용 중인 밴드
3. 통신사가 해당 위치와 요금제에서 사용하는 밴드만 선택합니다. 근거가 없으면 모든 지원 밴드를 유지하는 것이 안전합니다. LTE 목록을 전부 해제하면 안 됩니다. 5G NSA는 LTE 앵커 밴드가 있어야 5G가 붙을 수 있습니다.
4. **적용**을 누르고 확인 창의 LTE/NR 변경 내용을 확인합니다. 전파가 잠시 끊길 수 있습니다. 기기 관리 Wi-Fi/LAN에 연결된 상태에서 진행하면 셀룰러가 내려가도 LuCI 화면을 계속 사용할 수 있습니다.
5. Floop3가 망 등록을 기다립니다. 일정 시간 안에 등록되지 않으면 이전 밴드 설정으로 되돌리고, 되돌림 결과를 화면에 표시합니다. 페이지를 닫지 말고 작업 상태를 확인합니다.
6. 완료 후 등록 사업자, 등록 상태, 접속 방식, 현재 연결 밴드와 WAN 상태를 확인합니다. `LTE`가 보이고 `5G`가 비어 있으면 NSA 구성에서 NR이 아직 추가되지 않은 것일 수 있습니다. 지원 목록에 있다는 사실만으로 해당 위치의 신호·통신사 허용·망 등록이 보장되지는 않습니다.

저장한 밴드 조합은 Floop3가 부팅 때 다시 적용할 수 있습니다. 모뎀의 현재 허용 마스크는 재부팅 시 순정 기본값으로 돌아갈 수 있으므로, 재부팅 후에는 페이지에서 런타임 연결 밴드와 등록을 다시 확인합니다.

## 4. 연결 문제를 순서대로 나누기

| 화면 상태 | 확인할 것 |
|---|---|
| SIM 없음/읽을 수 없음 | 카드 방향·장착·규격, 물리 SIM 매핑, SIM 잠금/PIN 상태 |
| SIM `READY`, 망 미등록 | 통신사 서비스 가능 지역, 밴드 제한, 요금제·로밍 허용, 잠금 상태 |
| 망 등록, WAN/APN 미적용 | 현재 ICCID의 APN 프로필, 인증 방식, APN 적용 상태 |
| APN 적용, 인터넷 안 됨 | 요금제 데이터 권한, 데이터 잔량/차단, 사업자 제공 IP 방식, WAN 상태 |
| 밴드 적용 후 미등록 | 화면의 자동 복원 결과 확인. 반복해서 다른 조합을 연속 적용하지 말고 지원 밴드 전체로 복귀 |

Floop3 화면에서 실패 단계와 복원 여부를 먼저 확인합니다. 임의 AT 명령, 모뎀 공장 초기화, 재부팅을 연속으로 실행하지 마세요. 화면에 식별자 표시를 켠 경우 ICCID/EID/전화번호는 공개하지 마세요.
