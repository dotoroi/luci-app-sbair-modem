## English

### Connection Mode error handling

- Fixed the stale-helper fallback so a failed RPC in Connection Mode uses LuCI's gettext function instead of an undefined `i18n` global. This prevents `ReferenceError: i18n is not defined` when the cached shared helper does not expose `errorText()`.
- Added a regression fixture that forces this fallback path.

### Compatibility and installation

- This is an application bundle for the supported stock SoftBank Air 6 / SBA6D firmware scope. It is not a firmware image and does not target an inactive A/B slot directly.
- The global LuCI translation endpoint cache policy is unchanged. If Japanese translations remain after selecting Korean, clear site data for the router address and reload LuCI.
- Before upgrading, read the [installation and recovery guide](../INSTALL-NON-CODEX-EN.md) and run `sh install.sh --check` from the bundle.

### Checks

- Built and verified locally in WSL before publication.

## 日本語

### 接続モードのエラー処理

- 接続モード画面で共有ヘルパーの古いキャッシュにより`errorText()`が使えない場合のフォールバックを修正しました。未定義の`i18n`グローバルではなくLuCIのgettext関数を使うため、RPC失敗時の`ReferenceError: i18n is not defined`を防ぎます。
- フォールバックを実行する回帰fixtureを追加しました。

### 互換性とインストール

- 対象はサポート対象の純正SoftBank Air 6 / SBA6Dファームウェア向けアプリケーションバンドルです。ファームウェアイメージではなく、非アクティブのA/Bスロットへ直接インストールするものではありません。
- LuCI全体の翻訳エンドポイントのキャッシュ設定は変更していません。韓国語を選んでも日本語が残る場合は、ルーターアドレスのサイトデータを削除してLuCIを再読み込みしてください。
- 更新前に[インストール・復旧ガイド](../INSTALL-NON-CODEX-JA.md)を読み、バンドルから`sh install.sh --check`を実行してください。

### 検証

- 公開前にWSL上でビルドと検証を行いました。

## 한국어

### 연결모드 오류 처리

- 연결모드 화면에서 공용 도우미의 오래된 캐시 때문에 `errorText()`를 사용할 수 없을 때의 대체 처리를 수정했습니다. 정의되지 않은 `i18n` 전역 대신 LuCI gettext 함수를 사용해 RPC 실패 때 `ReferenceError: i18n is not defined`가 발생하지 않게 했습니다.
- 이 대체 경로를 강제로 실행하는 회귀 fixture를 추가했습니다.

### 호환성 및 설치

- 지원 대상인 순정 SoftBank Air 6 / SBA6D 펌웨어용 애플리케이션 번들입니다. 펌웨어 이미지가 아니며 비활성 A/B 슬롯에 직접 설치하는 파일도 아닙니다.
- LuCI 전역 번역 응답의 캐시 정책은 바꾸지 않았습니다. 한국어를 선택해도 일본어가 남으면 공유기 주소의 사이트 데이터를 지우고 LuCI를 다시 여십시오.
- 업데이트 전에 [설치·복구 안내](../INSTALL-NON-CODEX-KO.md)를 읽고 번들에서 `sh install.sh --check`를 실행하십시오.

### 검증

- 게시 전에 WSL에서 빌드와 검증을 진행했습니다.
