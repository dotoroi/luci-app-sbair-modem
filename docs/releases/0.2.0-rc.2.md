## English

### Preview candidate

This candidate fixes the Connection Mode error handler when the browser loads an older cached `tools.sbair` module. The view now falls back to LuCI's translator instead of throwing `sbair.errorText is not a function`. The router-mode manual documents cache refresh and recovery steps in English, Japanese, and Korean.

### Build status

- Built with Go 1.25.5 for Linux ARM64 with `CGO_ENABLED=0`.
- JavaScript syntax was checked. The repository shell packaging/check scripts and Go test suite were not run on this Windows host.
- Hardware feature validation is not claimed by this preview note.

## 日本語

### プレビュー候補

ブラウザーが古いキャッシュの`tools.sbair`モジュールを読み込んだ場合のConnection Modeのエラー処理を修正しました。`sbair.errorText is not a function`を再度発生させず、LuCIの翻訳機能へフォールバックします。キャッシュ更新と復旧手順を日本語・英語・韓国語のルーターモード案内に追加しました。

### ビルド状況

- Go 1.25.5でLinux ARM64向けに`CGO_ENABLED=0`でビルドしました。
- JavaScript構文を確認しました。このWindows環境ではリポジトリのシェル形式のパッケージ・検査スクリプトとGoテストを実行していません。
- 実機での機能検証を主張するものではありません。

## 한국어

### 미리보기 후보

브라우저가 오래된 캐시의 `tools.sbair` 모듈을 불러오는 경우 네트워크 연결 모드의 오류 처리를 보강했습니다. `sbair.errorText is not a function` 오류를 다시 내지 않고 LuCI 번역기로 대체 표시합니다. 한·영·일 라우터 모드 안내에 캐시 새로고침과 복구 방법을 추가했습니다.

### 빌드 상태

- Go 1.25.5로 Linux ARM64 대상, `CGO_ENABLED=0` 설정에서 빌드했습니다.
- JavaScript 구문 검사를 통과했습니다. 이 Windows 환경에서는 저장소의 셸 패키징·검사 스크립트와 Go 테스트를 실행하지 않았습니다.
- 실기 기능 검증을 주장하지 않습니다.
