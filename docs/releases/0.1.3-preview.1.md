## English

### Preview candidate

This preview combines the publication branch's expanded modem, Wi-Fi, network, and localized UI work with the release baseline's installer checks and recovery documentation.

### Compatibility and installation

- Intended for the supported stock SoftBank Air 6 / SBA6D firmware scope in the [compatibility guide](https://github.com/Floop3/luci-app-sbair-modem/blob/main/docs/FIRMWARE-COMPATIBILITY-EN.md). Metadata checks do not certify every feature.
- Read the [installation guide](https://github.com/Floop3/luci-app-sbair-modem/blob/main/docs/INSTALL-NON-CODEX-EN.md) and [access security guide](https://github.com/Floop3/luci-app-sbair-modem/blob/main/docs/INSTALL-ACCESS-EN.md) before installing.
- This is an application bundle, not a firmware image. It does not install itself or change router configuration automatically.

### Checks

- Windows Go 1.27.4 cross-build: Linux ARM64, `CGO_ENABLED=0`.
- Go test suite cross-compiled for Linux ARM64 and `go vet` passed; unit tests were not executed on Windows.
- `tools/package-release.sh` created the archive and Japanese/Korean LuCI catalogs.
- Archive SHA-256 and manifest source commit were checked. Hardware feature validation is not claimed by this preview note.

## 日本語

### プレビュー候補

公開ブランチのモデム、Wi-Fi、ネットワーク機能と多言語UIを、リリース版のインストーラー検査・復旧資料と統合した候補です。

### 互換性とインストール

- [互換性ガイド](https://github.com/Floop3/luci-app-sbair-modem/blob/main/docs/FIRMWARE-COMPATIBILITY-JA.md)に記載した純正SoftBank Air 6 / SBA6Dの範囲が対象です。メタデータ検査は全機能の動作保証ではありません。
- インストール前に[インストールガイド](https://github.com/Floop3/luci-app-sbair-modem/blob/main/docs/INSTALL-NON-CODEX-JA.md)と[アクセス保護ガイド](https://github.com/Floop3/luci-app-sbair-modem/blob/main/docs/INSTALL-ACCESS-JA.md)を確認してください。
- これはアプリケーションのバンドルであり、ファームウェアイメージではありません。自動インストールやルーター設定変更は行いません。

### 検証

- Windows上のGo 1.27.4でLinux ARM64、`CGO_ENABLED=0`のクロスビルドを実行しました。
- Goテスト一式をLinux ARM64向けにクロスコンパイルし、`go vet`は成功しました。Windowsではテストを実行していません。
- `tools/package-release.sh`でアーカイブと日本語・韓国語LuCIカタログを生成しました。
- アーカイブのSHA-256とmanifestのソースコミットを確認しました。このノートは実機機能の検証を主張しません。

### 검증

- Windows Go 1.27.4로 Linux ARM64, `CGO_ENABLED=0` 크로스 빌드를 수행했습니다.
- Go 테스트 전체를 Linux ARM64 대상으로 교차 컴파일했고 `go vet`를 통과했습니다. Windows에서는 테스트를 실행하지 않았습니다.
- `tools/package-release.sh`로 압축 파일과 일본어·한국어 LuCI 카탈로그를 만들었습니다.
- 압축 파일 SHA-256과 manifest의 소스 커밋을 확인했습니다. 이 안내는 실기 기능 검증을 주장하지 않습니다.
