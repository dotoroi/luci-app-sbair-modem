## English

### Update fixes

- The installer recognizes additional known Floop3 network-mode helper revisions when upgrading, while continuing to stop on unknown implementations.
- USB NIC state checks use BusyBox-compatible file metadata commands on the Air 6 firmware.
- The adblock DNS service restarts cleanly during upgrades, removes orphaned processes from older versions, and waits for its DNS listener before redirecting client traffic.
- The Connection Mode page now handles a stale cached LuCI helper after an update without throwing `sbair.errorText is not a function` from its own error handler. If the old page remains cached, hard-refresh LuCI after updating.

### Compatibility and installation

- For the supported stock SoftBank Air 6 / SBA6D firmware scope in the [compatibility guide](../FIRMWARE-COMPATIBILITY-EN.md). Metadata checks are not a complete functional certification.
- Before upgrading, read the [installation and recovery guide](../INSTALL-NON-CODEX-EN.md) and run `sh install.sh --check` from the bundle.
- This is an application bundle, not a firmware image. It does not change router settings automatically.

### Checks

- The tagged release workflow runs Go tests and vet, shell/publication fixtures, and packaged install/removal checks before publishing the archive.

## 日本語

### アップデートの修正

- アップデート時に既知の旧Floop3ネットワークモードヘルパーを追加認識します。未知の実装は引き続き上書きせず停止します。
- USB NICの状態確認をAir 6ファームウェアのBusyBoxで使えるファイル情報コマンドに変更しました。
- 広告ブロックDNSサービスをアップデート時に正しく再起動し、旧バージョンの孤立プロセスを終了してから、DNSリスナーを確認してクライアントの通信を転送します。
- Connection Mode画面で、アップデート後に古いLuCIヘルパーがキャッシュされていても、エラー処理自身が`sbair.errorText is not a function`を発生させないようにしました。古い画面が残る場合はLuCIを強制再読み込みしてください。

### 互換性とインストール

- [互換性ガイド](../FIRMWARE-COMPATIBILITY-JA.md)に記載した純正SoftBank Air 6 / SBA6Dファームウェアが対象です。メタデータ検査は全機能の動作保証ではありません。
- アップデート前に[インストール・復旧ガイド](../INSTALL-NON-CODEX-JA.md)を読み、バンドルから`sh install.sh --check`を実行してください。
- これはアプリケーションのバンドルであり、ファームウェアイメージではありません。ルーター設定を自動変更しません。

### 検証

- タグのリリースワークフローでGoテストとvet、シェル・公開用fixture、パッケージのインストール・削除検査を行い、合格後にアーカイブを公開します。

## 한국어

### 업데이트 수정

- 업데이트 시 Floop3 네트워크 모드 도우미의 알려진 이전 버전을 추가로 인식합니다. 알 수 없는 구현은 계속 덮어쓰지 않고 중단합니다.
- USB NIC 상태 확인을 Air 6 펌웨어 BusyBox에서 사용할 수 있는 파일 메타데이터 명령으로 바꿨습니다.
- 광고 차단 DNS 서비스를 업데이트 중 정상적으로 재시작하고, 이전 버전의 고아 프로세스를 정리한 뒤 DNS 리스너를 확인하고 단말 트래픽을 전달합니다.
- 업데이트 뒤 이전 LuCI 도우미 캐시가 남아도 네트워크 연결 모드 화면의 오류 처리기가 `sbair.errorText is not a function`을 다시 일으키지 않도록 했습니다. 이전 화면이 계속 보이면 LuCI를 강력 새로고침하세요.

### 호환성 및 설치

- [호환성 안내](../FIRMWARE-COMPATIBILITY-KO.md)에 적힌 순정 SoftBank Air 6 / SBA6D 펌웨어 범위가 대상입니다. 메타데이터 검사는 모든 기능의 동작 보증이 아닙니다.
- 업데이트 전에 [설치·복구 안내](../INSTALL-NON-CODEX-KO.md)를 읽고, 번들에서 `sh install.sh --check`를 실행하십시오.
- 이 파일은 펌웨어 이미지가 아닌 앱 번들이며, 공유기 설정을 자동으로 바꾸지 않습니다.

### 검증

- 태그 릴리스 워크플로가 Go 테스트와 vet, 셸·배포 fixture, 패키지 설치·제거 검사를 통과한 뒤 압축 파일을 게시합니다.
